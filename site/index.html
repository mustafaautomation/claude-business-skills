Install it where you work

A skill uploaded in one product is not automatically available in the others. Pick the surface and install there.

claude.ai

Download a zip above, or from downloads/. Settings, Capabilities, Skills, upload. Code execution has to be on, or the script never runs.

Claude Code

claude plugin marketplace add mustafaautomation/claude-business-skills
claude plugin install business-skills@quvantic-skills

API

POST the zip to /v1/skills, then pass the returned id in container.skills with the code execution tool. The container cannot install packages.
